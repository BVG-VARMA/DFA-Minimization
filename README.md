# 🔹 DFA Minimization

A web-based application for minimizing Deterministic Finite Automata (DFA) using the state equivalence method.

<p align="center">




</p>

## 🚀 Live Demo

### Try the application directly:

👉 **[Open DFA Minimization Application](https://bvg-varma.github.io/DFA-Minimization/)**

The application allows users to enter a DFA and perform minimization through an interactive interface.

## ✨ Features

* Enter DFA states
* Define input symbols
* Specify initial state
* Specify final states
* Enter transition information
* Identify equivalent states
* Generate the minimized DFA
* Interactive web interface

## 🧠 Concept Used

The application is based on the **DFA minimization / state equivalence method** studied in Formal Languages and Automata Theory (FLAT).

Basic process:

```text
Input DFA
   ↓
Check Reachable States
   ↓
Identify Equivalent States
   ↓
Merge Equivalent States
   ↓
Minimized DFA
```
